[🌐 Switch to English Version](README.md)

---

## ✨ ویژگی‌های کلیدی

- 🚀 **معماری اختصاصی MVC:** جداسازی کامل منطق برنامه (مدل، ویو و کنترلر) برای نگهداری آسان‌تر.
- 🛣️ **سیستم روتینگ مبتنی بر Regex:** سیستم مسیریابی قدرتمند که از الگوهای پویا (مانند `/post/123`) پشتیبانی می‌کند.
- 🎨 **رابط کاربری مدرن:** طراحی کاملاً ریسپانسیو و زیبا با استفاده از **Tailwind CSS**.
- 🛠️ **مسیریابی هوشمند:** مدیریت خودکار وضعیت فعال (Active State) منوها با استفاده از PHP و JavaScript.
- 📂 **ساختار URL تمیز:** ساختار آدرس‌ها مطابق با اصول SEO.

## 🏗️ ساختار پروژه

این پروژه از الگوی MVC پیروی می‌کند:

- **`App/`**: شامل هسته اصلی برنامه.
    - **`Controllers/`**: مدیریت درخواست‌های کاربر و تعامل با مدل‌ها.
    - **`Models/`**: مدیریت منطق داده‌ها و تعامل با دیتابیس.
    - **`Core/`**: شامل موتور اصلی (Router، کلاس پایه کنترلر و غیره).
- **`Views/`**: شامل قالب‌های HTML و اجزای رابط کاربری (با Tailwind CSS).
- **`Front/`**: نقطه ورود اصلی اپلیکیشن (`index.php`).
